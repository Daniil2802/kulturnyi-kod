Команда проекта

О «Культурном коде»

Проект превращает знакомство с культурным наследием Кузбасса в интерактивное исследование.

Принцип работы с информацией

Каждый культурный объект должен иметь указание на источник. Для наполнения используются материалы музеев, официальных культурных учреждений, научные и образовательные публикации. Демонстрационные карточки в прототипе не являются финальным контентом.

Технологии прототипа

  • HTML5 — структура страниц
  • CSS3 — адаптивная визуальная система
  • JavaScript — каталог, фильтры и коллекция
  • LocalStorage — сохранение выбранных объектов в браузере
  • JSON/JavaScript-данные — модель культурных объектов

Следующий этап

Подключение базы данных, админ-панели для редакторов, авторизации и генерации изображения «Мой культурный код» для публикации в социальных сетях.
