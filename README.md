# Культурный код — интерактивный прототип

Демонстрационный статический сайт в формате культурной лавки о народах Кузбасса.

## Как запустить

Откройте `index.html` в браузере. Для локального сохранения выбранных товаров используется LocalStorage.

## Основные сценарии

1. Гость знакомится с проектом через главную страницу-приглашение в культурную лавку.
2. В лавке фильтрует объекты по народу и категории.
3. Открывает отдельную карточку товара с кратким описанием, историей и источником.
4. Добавляет товары в культурный чек для друга или близкого человека.
5. Указывает адресата, удаляет лишние позиции и отправляет чек-картинку вместе со ссылкой-приглашением. По ссылке друг увидит чек и сможет собрать свой. Также чек можно распечатать или сохранить в PDF.

## Структура

- `index.html` — главная страница.
- `catalog.html` — каталог культурных объектов.
- `item.html?id=1` — отдельная карточка выбранного объекта.
- `collection.html` — культурный чек для близкого человека.
- `peoples.html` — страницы о народах.
- `about.html` — информация о проекте.
- `css/style.css` — визуальное оформление.
- `js/data.js` — демонстрационные данные объектов.
- `js/catalog.js`, `js/item.js`, `js/collection.js` — логика страниц.

## О контенте

Карточки показывают структуру интерфейса и требуют экспертной проверки перед публичным использованием. Источники указаны в карточках; реальные фотографии и финальные формулировки нужно согласовать с музеями и специалистами.
