# Культурный код — прототип

Это демонстрационный статический прототип концепции сайта.

## Как запустить
Откройте `index.html` в браузере.

## Технологии
- HTML5
- CSS3
- JavaScript
- LocalStorage для демонстрации коллекции
- Данные объектов хранятся в `js/data.js`

## Логика
1. Пользователь знакомится с народами.
2. Открывает каталог.
3. Фильтрует объекты по народу и категории.
4. Добавляет объекты в «Мою коллекцию».
5. Получает страницу «Мой культурный код».
6. В будущем результат можно превратить в изображение для публикации.

## Важно о контенте
Демонстрационные карточки — это структура интерфейса, а не финальная редакция исторических/этнографических сведений. Перед публикацией каждый объект должен пройти проверку по источнику и, желательно, экспертную редактуру.

Для первичного наполнения подходят материалы:
- Кузбасского государственного краеведческого музея — этнографическая коллекция шорцев и телеутов.
- Министерства культуры и национальной политики Кузбасса — материалы о региональных этнокультурных проектах.
- Государственной научной библиотеки Кузбасса — материалы выставок.
- Других музейных и научных учреждений региона.
